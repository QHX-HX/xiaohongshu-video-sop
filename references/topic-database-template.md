# 选题库模板

> 记录所有候选选题并打分，配合 `scripts/score_topics.py` 使用。

```markdown
---
type: topic
tags: [选题库, #方向]
status: 待选
---

# 选题：<一句话主题>

## 基本信息
- 知识类型：认知颠覆 / 方法论 / 经验总结 / 行业洞察
- 目标人群：
- 一句话价值承诺：

## 打分（0-5）
| 维度 | 得分 | 备注 |
|------|------|------|
| 信息差 |  |  |
| 实用性 |  |  |
| 传播性 |  |  |
| 个人特色 |  |  |

- 总分：__ / 20（≥12 值得做）

## 漏斗开口（决定流量上限，详见 traffic-funnel-topic-upgrade.md）
- 理解门槛（降维打击）：低 / 中 / 高，改造思路：
- 情绪点（剥离「事」后的「情」）：
- 开口改造（三招选用）：私事公办 / 痛点嫁接 / 极度反差，原表述 → 改造后表述：

## 三问检测（任一 no 则回改，不要开拍）
| 问题 | 结果 |
|------|------|
| 覆盖度：卖煎饼的大妈能听懂吗？ |  |
| 关联度：「这说的不就是我吗」？ |  |
| 情绪度：有生气/惊讶/想笑吗？ |  |

- Gate 结论：PASS / REVISE

## 标题候选（3 个）

3. 

## 埋词
- 主词：
- 长尾词：

## 状态流转
- [ ] 待选 → 已采纳 → 已发布
```

**批量打分**：把多条候选选题写成 CSV，运行 `python scripts/score_topics.py --input topics.csv` 自动排序。
