# 认知纠偏脚本模板（进阶叙事）

> 适用于知识类视频的进阶脚本法：不直接给结论，而是带观众走完「我原来想错了」的认知转变，产生强烈的获得感。
> 叙事策略层，与「脚本时间结构」（节奏骨架层）互补，可填充进时间结构各时段。

## 一、核心原则

> 把「输出答案」变成「完成一次认知纠偏」。设计一条引导路径，让观众自己走完认知转变。

## 二、开场：制造认知冲突（前 3 秒）

### A. 反常识观点（打破常规认知）
不要直给正确结论，而说一个反直觉的结论，制造"认知缺口"，防止大脑关闭。

| 直给结论（避免） | 反常识钩子（采用） |
|------------------|----------------------|
| 坚持更新很重要 | 做自媒体最难的不是坚持更新，而是你坚持更新了半年，依然没形成一套能复制的方法论 |
| 内容要垂直 | 内容越垂直越没人看？真正的问题可能是你没先定义清楚给谁看 |
| 涨粉靠自律 | 那些"自律"的人，很多都栽在不敢停下来验证方法 |

### B. 隐藏关键信息（误导-期待-反转）
讲案例/故事时，刻意隐藏一个关键信息，先让观众形成初步判断，再揭示真相制造反转，带来智力愉悦。

```
误导：先给一个看似合理的判断（隐藏真相）
期待：观众据此形成预期，心里有答案
反转：揭示隐藏关键信息，推翻预期
```

## 三、中段：引导思考，而非灌输

### A. 苏格拉底式提问（连续追问）
通过提问让观众自己发现问题的本质，而不是直接喂答案。

| 观众的常见误区 | 引导性反问（苏格拉底式） |
|----------------|--------------------------|
| 涨粉慢是因为不够自律 | 是不是所有自律的人都能做好自媒体？那为什么有些人日更数据还是很差？ |
| 没流量是内容不够多 | 为什么有人发的少却条条爆？问题会不会不在数量，而在选题的竞争力？ |
| 做不好是因为不会剪 | 别人 3 分钟口播也能爆，剪得花哨真的是关键吗？ |

**提问设计要点**：
- 一次只推进一个认知点，不要连抛多个问题。
- 问句要能"逼"观众在心里给出答案。
- 提问后停顿 1-2 秒，留给观众思考空间。

### B. 从现象下判断（只有你会说的判断）
不只罗列大家已知的现象，要给出一个清晰、只属于你的判断，让观众"原来如此"、记住你。

```
现象：大家都看到 / 都在说的事情
判断：你给出的独特解读或因果解释（核心增量）
```

## 四、完整认知路径（四步，缺一不可）

让观众跟着走完才会信服：

```
① 用户原来怎么想   → 说出他们普遍的想法（"你懂我"）
② 这个想法为什么有问题 → 指出局限性（制造"那我该怎么办"的好奇）
③ 真正的原因是什么 → 给出新的、更深刻的解释（完成认知纠偏）
④ 接下来应该怎么做 → 具体可操作的行动建议（明确方向）
```

### 逐段填写框

**① 你原来怎么想**
> 你是不是也觉得：____________________

**② 这个想法为什么有问题**
> 但问题是：____________________（指出局限/反例）

**③ 真正的原因**
> 其实真正决定结果的是：____________________（更深刻的解释，完成纠偏）

**④ 接下来怎么做**
> 你可以这样做：1. ____ 2. ____ 3. ____

## 五、完整示例脚本（以"自媒体涨粉"为例）

```
[开场·反常识] 做自媒体最难的不是坚持更新，而是你坚持更新半年，依然没有一套能复制的方法论。

[① 原来怎么想] 你是不是也觉得，涨粉慢是因为自己不够自律、更新不够勤？

[② 为什么有问题] 但你有没有发现，那些天天日更的人，数据未必比周更的人好。
（苏格拉底式反问）是不是所有自律的人，都能把自媒体做好？

[③ 真正的原因] 其实真正决定涨粉的，不是更新频率，而是你每一条内容有没有形成"可复制的竞争力"——
你能不能总结出：什么样的选题、什么样的表达，是反复能出效果的。

[④ 怎么做] 具体三步：
1. 每月挑出数据最好的 3 条，拆解它们的选题和钩子；
2. 把共性写成一张"验证清单"，照着重复；
3. 持续迭代，直到形成你专属的方法论。

[收尾金句] 自律只是入场券，方法论才是护城河。
```

## 六、使用自查

- [ ] 开头是反常识/反直觉，而非正确结论
- [ ] 讲了"用户原来怎么想"（先共情）
- [ ] 指出该想法的局限（制造好奇）
- [ ] 给出更深刻的解释（纠偏）
- [ ] 有苏格拉底式提问引导思考，而非直接灌输
- [ ] 结尾有具体可执行的行动建议
- [ ] 必要时用"误导-期待-反转"结构制造反转
