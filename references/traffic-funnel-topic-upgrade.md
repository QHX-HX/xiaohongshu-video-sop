# 流量漏斗选题法：开口决定流量上限

> 核心命题：**选题决定流量漏斗的开口大小**。视频播放过程是漏斗，观众每秒都在流失；开口小（选题窄），后面文案、剪辑、拍摄承接做得再好也接不住几滴水。绝大多数视频数据差，不是内容质量不行，而是选题把流量挡在了门外。
>
> 金句：**选题定生死，内容定高低，算法当裁判，人性是核心。**

适用时机：Step 2 选题时先评估漏斗开口，再决定做不做、怎么改造；发视频前用「三问检测器」最后把关。

---

## 一、好选题的两条核心标准

### 标准 1：对观众大脑的降维打击（理解门槛低到尘埃里）
- 观众刷短视频时大脑是「省电模式」，**所有需要动脑的选题都在把流量拒之门外**。
- 高手不展示专业，只负责**把专业翻译成人话**：讲法条没人听，讲「张三掉进粪坑」全网爆款——极少数人懂法律，但所有人都爱听故事。
- 自检：这个话题需要观众具备什么知识背景？门槛越高，漏斗开口越小。

### 标准 2：必须击穿情绪（剥离「事」，上升到「情」）
- 所有知识技能都有圈层：讲钓鱼美妆人群不看，讲代码宝妈不看，过度垂直 = 亲手把流量门焊死。
- 唯一能穿透所有壁垒的是**情绪**。李子柒卖的不是腌酸菜、砍竹子（有国界的事），而是「逃离城市、回农村静静」的向往（全人类通用的情）。
- 自检：这个话题剥掉具体的事之后，还剩什么情绪？没有情绪 = 无感 = 被大脑自动过滤。

## 二、三个傻瓜式选题改造法（把窄选题撑大漏斗）

发视频前逐条套一遍，流量至少扩大一个量级：

### 第 1 招：私事公办 —— 解决「关我屁事」
- 不要做自嗨的日记（「我今天面试了一家奇葩公司」→ 没人关心你的生活），要做千万人的嘴替。
- 改造公式：**我 → 我们，经历 → 观点**。
- 例：「我去面试了一家很奇葩的公司」→「00 后整顿职场，为什么我建议你面试一定要怼回去」。
- 私事变公事，漏斗扩大 100 倍。

### 第 2 招：痛点嫁接 —— 解决「过于垂直」
- 技能教学类必学。大众听不懂你的技术，但都懂技术背后的痛苦。
- 改造公式：**专业话题 → 嫁接到大众焦虑/普遍痛点**。
- 例：「怎么用 Excel 的 VLOOKUP 函数」→「因为不会这一个公式，我被老板骂着加了 3 天班」。
- 不卖 Excel 教程，卖「不想加班的欲望」；受众从想学技术的人扩到所有不想加班的职场人。

### 第 3 招：极度反差 —— 解决「平平无奇」
- 大脑自动过滤符合常理的东西，只有打破认知才能强行撑大漏斗。
- 改造公式：**高预期 vs 低待遇 / 强对比组合**（身份反差、价格反差、场景反差、认知反差）。
- 例：「推荐一家好吃的路边摊」（一天产出 100 万条，石沉大海）→「开保时捷去吃人均 8 块钱的路边摊，老板竟然看不起我」。
- 你要么让人羡慕，要么让人嫉妒，绝不能让人无感。

> 与本技能原有体系的衔接：三招是「传播机制层 4 条标准」的**具体改造工具**——先用内容价值层 4 条标准判断「值不值得做」，再用漏斗开口判断「能做多大」，开口不够就上三招改造，最后用三问检测器把关。

## 三、选题检测器（发布前三问）

拿着定好的选题/标题问自己三个问题，**只要有一个答案是 no，就回去重改，不要浪费时间做视频**：

| # | 问题 | 通过标准 |
|---|------|----------|
| 1 | **覆盖度**：这个话题我家楼下卖煎饼的大妈能听懂吗？ | 零基础人群也能听懂，无专业门槛 |
| 2 | **关联度**：这个话题能让观众觉得「这说的不就是我吗」？ | 能精准戳中某个普遍处境/身份 |
| 3 | **情绪度**：这个话题能让人产生哪怕一丝丝的生气、惊讶甚至想笑吗？ | 至少触发一种明确情绪，不是无感 |

可用 `scripts/topic_gate_check.py` 结构化走一遍三问并留档（输出 gate 结论：PASS / REVISE）。

## 四、常见误区对照

| 误区 | 真相 |
|------|------|
| 数据差 = 内容质量不行，去学文案剪辑拍摄 | 多数情况是选题开口太小，在错误的方向上拼命 |
| 越专业越显得厉害 | 高手只负责把专业翻译成人话，展示专业 = 赶客 |
| 垂直 = 精准 = 好 | 过度垂直亲手焊死流量门，用情绪穿透圈层 |
| 追热点必爆 | 开口由选题决定，热点只是给开口借势 |
