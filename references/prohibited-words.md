# 小红书违规词与内容红线清单

> 创作与发布前对照检查。规则会随平台更新，发布前务必以小红书官方「社区规范 / 创作中心」最新公告为准。

## 一、绝对禁用 / 高风险词（夸大与绝对化）
- 最、第一、顶级、国家级、唯一、独家、全网第一、史无前例
- 百分百、绝对、一定、保证、稳赚、必火、爆款保证
- 药到病除、根治、永不反弹（医疗/保健类尤其危险）

## 二、医疗 / 健康类红线（知识类创作者高发）
- 不得宣称治疗、疗效、根治，不得使用"医生推荐""专家认证"等无依据背书
- 涉及疾病诊断、用药建议时必须提示"非医疗建议，请咨询专业医生"

## 三、财经 / 投资类红线
- 不得承诺收益、不得荐股、不得使用"稳赚""翻倍""带单"等表述
- 投资建议需提示风险，避免被认定为非法荐股或诱导投资

## 四、引流 / 导流违规
- 不得诱导站外交易、留个人联系方式导流到微信等
- 不得"互粉""互赞"等违规互动；不得买卖粉丝、刷量

## 五、版权 / 肖像权
- 不得搬运、盗用他人原创图文/视频
- 涉及真实人物肖像、他人案例需获得授权

## 六、其他红线
- 不得发布违法违规、色情低俗、暴力、歧视内容
- 不得制造焦虑贩卖恐慌、夸大虚假宣传
- 评论区和私信同样受规范约束

- [ ] 素材均为原创或有授权
- [ ] 无导流、互粉等违规动作
